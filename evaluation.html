Evaluation Guide

Each submitted itinerary is checked by an automatic verifier that enforces hard constraints (environment feasibility and logical correctness) and measures soft preferences (traveller-oriented quality signals).

Evaluation Metrics

Environment Constraints

Environment constraints assess whether the information in the output plan is consistent with the provided sandbox environment, measuring the feasibility of each itinerary. See also: Environment Constraint documentation.

$$ \text{EPR-micro} = \frac{\sum_{p \in P} \sum_{c \in \textit{Env}} \mathbf{1}_{\text{passed}}(c,p)}{|P| \cdot |\textit{Env}|} $$
$$ \text{EPR-macro} = \frac{\sum_{p \in P} \prod_{c \in \textit{Env}} \mathbf{1}_{\text{passed}}(c,p)}{|P|} $$

Conditional Logic Constraints

Conditional logic constraints evaluate how well the output plan satisfies personalised user requirements under the premise that environment constraints are already met.

$$ \text{C-LPR} = \frac{\sum_{p \in P} \mathbf{1}_{\text{passed}}(\textit{Env},p) \cdot \sum_{c \in C_p} \mathbf{1}_{\text{passed}}(c,p)}{|P|} $$

P — set of output plans; Cp — set of constraint requirements in the query corresponding to plan p; 1passed(c,p) — 1 if constraint c is satisfied in plan p, 0 otherwise.

Hard Constraint Pass Rate

FPR (Final Pass Ratio) expresses the proportion of output plans that satisfy all environment constraints and logical constraints simultaneously.

$$ \text{FPR} = \frac{\sum_{p \in P} \mathbf{1}_{\text{passed}}(\textit{Env},p) \cdot \prod_{c \in C_p} \mathbf{1}_{\text{passed}}(c,p)}{|P|} $$

Preference Evaluation

TPC provides three common travel preference indicators:

Daily Average Attractions Visited (DAV) — more is better. Normalised to [0, 4].

$$ \text{DAV-score} = \frac{\textit{DAV} - 0}{4} $$

Averaged Transportation Time (ATT) — less is better. Clamped to [15, 120] minutes.

$$ \text{ATT-score} = \max\!\left(\min\!\left(\frac{120 - \textit{ATT}}{120 - 15},\ 1\right),\ 0\right) $$

Daily Dining Recommendations (DDR) — more is better. Normalised to [0, 3].

$$ \text{DDR-score} = \min\!\left(\frac{\textit{DDR} - 0}{3 - 0},\ 1\right) $$

Overall Score

$$ \text{Overall Score} = 10\%\ \text{EPR-micro} + 10\%\ \text{EPR-macro} + 25\%\ \text{C-LPR} + 40\%\ \text{FPR} + 5\%\ \text{DAV-Score} + 5\%\ \text{ATT-Score} + 5\%\ \text{DDR-Score} $$
Hard constraints · EPR-micro, EPR-macro, C-LPR, FPR — 85% Soft preferences · DAV, ATT, DDR — 15%

4. Local Evaluation

Use eval_tpc.py to score your results locally. Place outputs under chinatravel/results/ and run:

python eval_tpc.py --splits <current_split> --method <your_method_name> --lang en
